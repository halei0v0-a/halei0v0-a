# 静态博客管理后台分享

> 之前折腾这个博客的时候，最烦的就是改点东西要开编辑器、翻配置、找数组，改完还得敲一遍 `pnpm build`。后来干脆给博客写了个本地管理后台，所有日常操作都在浏览器里点一点就完事。这篇分享一下它都能干些啥。

## 后台是啥

博客本身是纯静态站（Astro 构建），没有数据库，内容全部写在代码里的。所谓"管理后台"，其实就是跑在本机的一个小服务，帮你把**改文件这件事**包了一层界面：

- 启动方式：双击项目根目录的 `start-admin.bat`，或者手动执行 `node admin/server.mjs`
- 默认地址：`http://localhost:4830`（可以用环境变量 `ADMIN_PORT` 改端口）
- 零依赖：只用了 Node 自带的模块，不需要装任何东西

整个后台就俩文件（`admin/server.mjs` + `admin/index.html`），改配置、改数据、写文章、构建部署全在这一页里。

## 都能干什么

后台首页是几个功能卡片，点进去就是对应的模块：

### 1. 开关管理

博客的开关（比如显示公告、开启评论区、隐藏某块组件）都写在 `src/config.ts` 和 `src/config/commentConfig.ts` 里，一个布尔值控制一个功能。后台会把这些开关全部列出来，带路径和注释，点一下按钮就切换，不用再去代码里找是哪个变量。

### 2. 数据管理

博客的友情链接、项目、技能、时间线、番剧、设备、日记，这七类数据都存在 `src/data/` 下的 `.ts` 文件里。后台支持三种玩法：

- **直接编辑**：把整个数据当 JSON 打开，改完保存，自动转回 TypeScript 写回文件
- **表单添加**：按字段填表（名称、链接、标签这些），不用记数据结构
- **条目管理**：列出所有条目，删掉不想要的

### 3. 内容配置

站点名称、个人简介、公告、导航栏菜单、社交链接这类文案，不用去 config.ts 里大海捞针，后台按分组列出来，直接改对应的输入框就行。改完保存，重新构建后生效。

### 4. 文章管理

写文章是本后台的重头戏，内置了一个完整的 Markdown 编辑器：

- **三种视图**：编辑 / 分屏 / 预览，右边就是实时渲染效果
- **Front Matter 配置**：标题、日期、分类、标签、封面图，还有草稿、置顶、加密（带密码）、语言、许可证这些进阶字段，弹窗里填好自动写进文件头部
- **模块面板**：常用语法一键插入——标题、列表、代码块、引用这些基础的，还有 Note / Warning 提示框、GitHub 卡片、Mermaid 图表、视频嵌入，以及几套现成的文章模板（标准文章、加密文章、置顶公告、技术教程）
- **查找替换**：长文改词不用手动翻
- **导入导出**：支持导入 `.md` / `.txt` / `.html`，导出成 Markdown 文件带走
- **快捷键**：`Ctrl+S` 保存、`Ctrl+B` 加粗、`Ctrl+F` 查找，括号自动补全

文章列表能看到每篇的标题、日期、字数、分类和标签，草稿和置顶有醒目标记，支持搜索。新建文章会自动生成 `post编号` 目录和模板（默认是草稿状态，不会误发）。

### 5. 构建部署

改完东西总得重新构建才能上线，后台里点一下"开始构建"就行：

- 一键执行 `pnpm build`，构建日志直接显示在页面上
- 构建历史记录最近 10 次，成功失败一眼看得出
- 内置 dev server 启动/停止按钮，想在本地预览效果就开 `http://localhost:4321`

## 关于备份

后台所有写操作（改开关、存数据、保存文章、删文章）**都会先把原文件备份到 `admin/backups/`**，文件名带时间戳。删文章的时候整个目录（包括里面的图片）都会先备份再删，手滑了也能找回来。后台首页右上角能直接看到当前有几份备份。

## 写在最后

这个后台是给本机用的，不是公网服务，平时写博客开它就行，不写就关掉，完全不影响线上。代码也不复杂，一个 Node 脚本加一个 HTML，想加功能自己往里塞就行。
