# 博客使用指南

> 你好呀，我是 **halei0v0**，欢迎来到我的小站 👋
>
> 这是一篇不怎么正经但非常详细的使用说明书，带你把这个博客里里外外玩明白。

## 关于这个博客

这个博客基于 **Astro** 构建，是一棵完完全全的**静态站点**：没有后端、没有数据库，打开页面基本就是秒开，还能部署到任何静态托管平台（EdgeOne Pages、Vercel、GitHub Pages 都行）。

所以你看到的文章、番剧列表、设备清单……全都是「写死」在代码里的数据，由我本人定期更新。也因此，**博客的每一次改版、每一篇新文章，都是我用脚投票的结果**——留下的一定是我觉得好玩的东西。

博客还集成了这些「外挂」：

- **Pagefind 全文搜索**：所有文章内容都被索引，搜啥都找得到
- **RSS / Atom 订阅**：想要第一时间收到更新？订阅就完事了
- **KaTeX 数学公式**：写公式像写文档一样自然
- **Expressive Code 代码块**：行号、主题、可折叠章节，看代码赏心悦目

## 逛博客的正确姿势

### 顶部导航栏

导航栏分为四个分组，一眼看懂全站结构：

| 分组 | 里面有什么 |
| --- | --- |
| **Links** | 我的 GitHub、导航主页（Guideline）、Bilibili |
| **My** | 番剧 / 日记 / 相册 / 设备 |
| **About** | 关于我、友情链接 |
| **Others** | 留言板 / 项目 / 技能 / 时间线 |

顶部有 **搜索按钮**，点击或按快捷键即可呼出全文搜索，支持中文分词，几毫秒出结果。

### 首页横幅

打开首页你会看到一个大大的横幅，背景可能是视频也可能是随机图片（来自我自建的随机图床），上面飘着我的欢迎语。它不仅是装饰——**横幅下方就是文章流**，往下滚就能看到全部文章。

### 文章列表

首页文章列表支持 **列表 / 网格** 两种布局，右上角可以随时切换。分类导航条帮你快速筛选某一类内容，比如只看「教程」或者只看「AI」。

文章卡片上会显示：封面图、分类、发布日期、摘要……看到感兴趣的，点进去就是了。

## 侧边栏宝箱

博客主内容区右侧（手机上会收到抽屉里）有一整排功能卡片，每一个都是宝贝：

- **个人资料**：我的头像和简介，下方是我的社交链接
- **公告**：站点的最新动态，我更新博客时会顺手改这里
- **分类 & 标签**：按主题归档的入口，标签的粒度更细
- **站点统计**：文章数、标签数、运行天数等硬数据
- **Umami 统计**：真实访问数据卡片（点击可跳转详细报表）
- **访问计数**：这个站被看了多少次，全靠它
- **站点信息**：构建信息、技术栈之类的彩蛋
- **日历**：按日期找文章，像翻日历一样
- **目录**：当前文章的标题大纲，点击即可跳转（在文章页显示）

## 文章页玩明白

点进一篇文章，你会看到：

- **字数与阅读时间**：心里有数，再决定要不要泡杯茶
- **目录（TOC）**：右侧悬浮目录，长文导航利器
- **代码块**：带行号，长代码可折叠，深色主题适配
- **数学公式**：`$E = mc^2$` 这类公式直接渲染
- **分享卡片**：文章底部有分享面板，生成带二维码的分享海报，发朋友圈、群里都方便
- **版权许可**：文章默认采用 CC BY-NC-SA 4.0，注明出处即可转载
- **相关文章 & 随机文章**：底部自动推荐，刷着刷着就刷到我别的文章了
- **上一篇 / 下一篇**：翻页按钮，文章按时间串成串
- **上次更新时间**：重要文章我会持续修订，标了时间方便你判断新旧

### 加密文章 🔒

少数文章是**加密**的（比如某些作业、某些不想公开的东东），标题旁边会有锁的标识，需要输入密码才能查看内容。密码？私聊我要 😎

## 评论区（Twikoo）

每篇文章和留言板都接了 **Twikoo** 评论系统：

- **匿名即可评论**，无需注册任何账号，填个昵称就能说话
- 支持 Markdown、表情包
- 会显示 **访客数** 和评论数

留言规则就一条：**友善**。看到有趣的评论区我也常在，欢迎来唠嗑。

## 观感与体验

- **深色 / 浅色主题**：右上角一键切换，默认跟随系统
- **音乐播放器**：右下角悬浮，网易云歌单，写代码 BGM 必备
- **看板娘**：一只蓝龙（Pio），可以拖拽到屏幕任意位置，点击对话会有反应。无聊的时候逗逗她
- **页面过渡动画**：Swup 驱动的平滑切换，翻页不闪白
- **横幅随机图**：每次刷新可能都不一样，今天是什么图纯看缘分
