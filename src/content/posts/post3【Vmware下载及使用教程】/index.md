虚拟机指通过软件模拟的具有完整硬件系统功能的、运行在一个完全隔离环境中的完整计算机系统，在实体计算机中能够完成的工作在虚拟机中都能够实现。

简单说，就是**在一台电脑里再开一台"电脑"**。这台"电脑"有自己的 CPU、内存、硬盘、网卡（都是模拟出来的），你可以往里面装任何操作系统，装坏了、中毒了，删掉重来就行，完全不影响你的实体机。

# 四、安装VMware

下载到的通常是一个 `.exe` 安装包，双击按提示走：

1. 接受许可协议
2. 选择安装位置（默认 C 盘即可，空间够就无所谓）
3. 勾选"增强型键盘驱动程序"（可选，一般勾上）
4. 等待安装完成，重启或直接打开

装完桌面会出现 VMware Workstation 图标，双击打开。

# 五、创建一台虚拟机

以最常见的"装一个 Linux 系统"为例，整个流程：

**1. 准备系统镜像**

去对应系统官网下载 ISO 镜像文件，比如 Ubuntu 的 [ubuntu.com/download](https://ubuntu.com/download/desktop)，或者 Windows 的官方镜像。

**2. 新建虚拟机**

VMware 主界面点「创建新的虚拟机」，选"典型（推荐）"，然后：

- 选择镜像文件，指向你下载的 ISO
- 设置虚拟机的用户名、密码（这就是你以后登录系统要用的）
- 给虚拟机起个名字，选择存放位置
- 设置磁盘大小（建议至少 20GB，选"将虚拟磁盘存储为单个文件"）
- 内存分配：至少给 2GB，想流畅点给 4GB

**3. 开始安装**

点「开启此虚拟机」，屏幕上会像实体机装系统一样进入安装界面。虚拟机窗口里的鼠标会被"捕获"，按 `Ctrl+Alt` 可以释放鼠标回到 Windows。

**4. 装系统**

按系统安装向导一步步来就行，和实体机装系统流程完全一样，只是慢一点。装完后重启，就能在虚拟机里用新系统了。

# 六、虚拟机常用操作

- **快照**：装系统前、配置环境前先打个快照，出问题一键还原，这就是虚拟机的最大好处
- **克隆**：想复制一个一模一样的虚拟机，右键克隆即可
- **共享文件夹**：菜单「虚拟机 → 设置 → 选项 → 共享文件夹」，把 Windows 的文件夹映射进虚拟机，两个系统之间传文件非常方便
- **调整硬件**：关机状态下可以随时改内存、加硬盘

# 七、常见问题

- **虚拟机启动报"Intel VT-x 未启用"**：进 BIOS 开启虚拟化（Intel Virtualization Technology / AMD-V），不同主板位置不同，搜一下自己主板的开法
- **鼠标卡在虚拟机里出不来**：按 `Ctrl+Alt`
- **虚拟机特别卡**：调大内存分配，或确认虚拟化已开启
- **和宿主机不能互相复制粘贴**：装 VMware Tools（虚拟机菜单里"安装 VMware Tools"），装完重启即可

虚拟机最大的价值就是**随便折腾不怕出事**——想玩 Linux、想测软件、想开服务器环境，先在虚拟机里试，全流程走通了再上实体机或服务器，省得把主力机搞坏。
